# GEO 产品介绍（生美老板版）

> **定位**：链接品牌与 AI 搜索时代，帮门店被 AI 看见、被顾客信任

## Part 01 · AI 搜索时代的变革与机遇

### 用户搜索行为在变

顾客不再只搜链接列表，而是直接问 AI：「附近哪家皮肤管理靠谱？」「敏感肌能不能做？」  
Gartner 预测：到 2028 年，全球约一半搜索流量将被 AI 搜索分流。**AI 已是新流量入口。**

### 决策路径前移

| 过去 | 现在 |
|------|------|
| 用户点进您的网页才认识您 | 用户在 **AI 回答里** 第一次形成印象 |
| 拼搜索排名 | 拼 **AI 是否引用、是否采信** 您的真实信息 |

**谁更早进入 AI 推荐语境，谁更早占据顾客心智。**

### 门店面临的三个变化

| # | 变化 | 对您意味着什么 |
|---|------|----------------|
| 1 | **品牌「隐形化」** | 顾客可能从不打开您的主页，只看 AI 综合答案 |
| 2 | **流量入口重构** | 接触时机前移到「AI 判断阶段」，不是点击之后 |
| 3 | **信任机制重塑** | AI 更信 **结构化、可验证、有来源** 的内容，不是堆砌关键词 |

**机遇：** 主动整理真实店务信息、按顾客问题写内容、持续监测——这就是 GEO（生成式引擎优化）。

## Part 02 · GEO 是什么 · 价值在哪

### GEO 一句话

**GEO = 让 AI 在回答顾客问题时，能识别、引用、采信您门店的真实信息。**

不是刷好评，不保证排名第一，不做虚构品牌。

### 我们怎么做（四步策略）

| 步骤 | 做什么 | 您感受到什么 |
|------|--------|--------------|
| **① AI 感知诊断** | 在您选的 AI（豆包/DeepSeek 等）上测：提到谁、爱引哪些网站 | 「开始分析」后看信源报告 |
| **② 品牌语料整理** | 把店名/项目/FAQ/案例整理成 AI 能读的结构化资料（知识库） | 一次录入，全渠道共用 |
| **③ 场景化内容与发布** | 按 **顾客真实问题** 写 FAQ/小红书/知乎，发到对应渠道 | 方案包确认 → 审稿 → 发布 |
| **④ 监测与迭代** | 每周测 AI 提及率、网页是否被引用；不好时给改方案建议 | 效果舱看数据，您确认后再改 |

> 类比：SEO 让人找到网页；**GEO 让人在 AI 答案里找到您。**

### 信任阶梯（生美版）

AI 更愿引用「多层可信信息叠在一起」的门店：

```
权威层  →  店名/地址/电话(NAP)、项目价格、资质说明、托管页 Schema
专业层  →  标准 FAQ、项目科普、知乎专业答
社交层  →  小红书笔记、点评/美团评价（整理后引用）
顾客层  →  真实案例、聊天/评价原话（脱敏后升格）
```

**我们的策略：** 先夯实权威层 + FAQ，再按场景写渠道内容——不是空口软文。

### GEO 与传统推广的区别

| | 传统 SEO / 堆文章 | **GEO（本产品）** |
|---|-------------------|------------------|
| 核心 | 关键词排名、发文数量 | **顾客问题（scenario）+ 可验证事实** |
| 用户行为 | 自己点链接筛选 | 直接看 AI 综合答案 |
| 内容要求 | 关键词密度 | 结构化 FAQ、Schema、fact 可追溯 |
| 我们的做法 | — | 先测信源 → 定场景 → 有依据才写 → 监测迭代 |
| 风险 | 易像广告、易被平台限流 | 机器审 + 您人工审，禁违规词 |

## Part 03 · 我们的做法 · 产品重点策略

### 不是盲发文章，是「认知资产 + 场景内容」

| 策略 | 说明 |
|------|------|
| **scenario-first（场景优先）** | 生产单元是顾客问法，如「敏感肌能不能做皮肤管理」——不是「皮肤管理 价格」堆词 |
| **KB 零幻觉** | 文案必须对应您录入的项目/FAQ/案例，系统核对后才可发布 |
| **先选 AI 再测信源** | 您勾选主攻 AI，系统先看 AI 爱引小红书还是知乎/点评，再决定发哪 |
| **篇数 = 问题数** | 标准包 3 个顾客问题 = 3 条内容，不是「小红书 5 篇」 |
| **2 次您确认** | 方案包确认一次、草稿审一次——系统不擅自发布 |

### 三舱体验 · 对外 3 步

| 舱 | 您说 | 系统做 |
|----|------|--------|
| **舱1 懂我** | 告诉我店的信息 | 建库 → 测信源 → 挖痛点 → 画像 → 竞品 |
| **舱2 定方案** | 看方案、确认出稿 | 定场景 → 生成 → 机器审 → **您审稿** |
| **舱3 出结果** | 发布、看效果 | 发布 → 监测 → 效果舱 → 策略建议 |

## Part 04 · 服务流程与阶段策略

### 闭环流程（从诊断到迭代）

```
录入店务信息
    ↓
AI 信源诊断（豆包/DeepSeek 等）
    ↓
方案包：定 2～3 个顾客问题 + 发哪些渠道
    ↓
生成内容 → 事实/合规双审 → 您确认
    ↓
发布（托管页自动 / 小红书知乎文案包）
    ↓
监测：提及率、网页引用、店页访问
    ↓
效果不好 → 系统给改方案草案 → 您确认 → 再迭代
```

### 三阶段建议（生美门店）

| 阶段 | 时间 | 重点 | 产出 |
|------|------|------|------|
| **① 基础构建** | 0～1 月 | NAP + FAQ + 2～3 场景内容 + 托管页 | AI 能读到您的标准答案 |
| **② 扩展深化** | 1～3 月 | 补案例/评价、加渠道、监测调优 | 关键问题里开始出现您 |
| **③ 认知巩固** | 3～6 月 | 持续监测、补缺口、更新 KB | 附近/项目类问题更稳定被引用 |

> GEO 不是一次性优化，是 **持续输出 + 持续修正 + 覆盖新问题** 的过程。

### 场景化策略（生美高频示例）

| 场景问法 | 内容形态 | 常见渠道 |
|----------|----------|----------|
| 附近哪家皮肤管理靠谱？ | 本地 FAQ + NAP + 案例 | 托管页、点评 |
| 敏感肌能不能做？ | 专业科普 FAQ | 托管页、小红书 |
| XX 店和竞品怎么选？ | 差异化说明（仅 KB 内事实） | 知乎、托管页 |
| 补水和水光有什么区别？ | 项目对比 FAQ | 托管页、小红书 |

**策略原则：** 一个问题 → 一条有依据的内容 → 一个主渠道，不一通发。

## Part 05 · 生美落地 · 交付什么

### 本地生活行业 GEO 场景（对齐行业实践）

| 行业特征 | 您的需求 | 我们已实现 |
|----------|----------|------------|
| 强地域、重口碑 | 「附近哪家」「好不好」 | 本地类 AI 探测 + 地图/点评信源分析 |
| 决策快、重信任 | 项目安全、价格透明 | FAQ + fact 核对 + 生美禁词合规 |
| 多平台种草 | 小红书/点评/知乎各有受众 | 分渠道 Skill，同一事实多种表达 |
| 要转化 | 看完想来店 | 托管页表单 + 效果舱追踪（V1.1 加咨询归因） |

### 三大交付模块

| 模块 | 做什么 | 您得到 |
|------|--------|--------|
| **AI + 托管页** | 自动生成带 Schema/FAQ 的门店页 | 几乎不用管，AI 易引用 |
| **AI + 场景内容** | 按顾客问题生成 FAQ/小红书/知乎稿 | 审一遍就能用 |
| **AI + 监测** | 固定问题每周测 AI 是否提到您 | 效果舱看趋势，不好给建议 |

### 交付效果（效果舱可见）

| 指标 | 说明 |
|------|------|
| AI 提及率 | 顾客常问的问题里，AI 有没有提到您 |
| 信源露出率 | AI 回答里有没有引用您的网页/内容 |
| 托管页访问/表单 | 有多少人看了店页、留了咨询 |
| 策略建议 | 连续 2 周偏低时，系统给改方案草案（需您确认） |

**我们卖的是：** 可见度趋势 + 可信内容体系 + 可复盘迭代，**不是**「保证 AI 第一」。

## Part 06 · 您怎么用 · 实操指南

### 您只需 3 步

**第 1 步 · 告诉我们店的信息**

- 勾选主攻 AI（如豆包）→ 填 NAP、项目、竞品、客户常问 → 点「开始分析」
- 约十几到几十分钟，系统显示：测信源 → 整理顾客问题…

**第 2 步 · 看方案、确认出稿**

- 一页方案包：建议回答哪几个问题、发到哪里
- 勾选 **2～3 个问题** →「确认并生成」→ 审一遍文案

**第 3 步 · 发布并看效果**

- 托管页自动发；小红书/知乎给 **标准文案包**（标题+正文+标签+怎么发）
- 效果舱看数据；不好时按建议补 FAQ/案例，您确认后再改

### 请您准备（录入 checklist）

| 必填 | 说明 |
|------|------|
| 店名、地址、电话 | NAP 基本信息 |
| ≥2 个项目 | 含价格或时长 |
| ≥3 条 FAQ | 常见 Q/A |
| ≥5 条聊天/评价 | 请去掉顾客手机号 |
| 2～3 家竞品 | 店名即可 |
| 主攻 AI | 如豆包 |

### 发到哪里

| 渠道 | 我们 | 您 |
|------|------|-----|
| 平台托管页 | 自动发 | 几乎不用管 |
| 小红书 / 知乎 | 标准文案包 | 复制发布 |
| 点评 / 美团 | 优化稿 + 指引 | 按指引改 |

### 费用（初版）

- **标准包**：3 个顾客问题 + 2 个 AI 监测 / 月
- **加购**：按问题条数，不是按渠道铺量
- 具体单价洽谈中

### 不是什么

- ❌ 不保证 AI 排名第一  
- ❌ 不刷好评、不虚构品牌  
- ❌ 不堆关键词、不铺量凑篇数  

### 多久见效

| 环节 | 周期 |
|------|------|
| 方案 + 诊断 | 约 1 天 |
| 内容生成 | 确认后数小时 |
| 首次监测 | 发布后约 24 小时 |
| 趋势变化 | 通常 4～8 周 |
