## 2. 任务清单

### 2.1 合并登录端点 → JSON only

**文件**: `backend/app/api/v1/auth.py`

改动：
1. **删除** `/login/json-login` 端点（第 66-85 行）
2. **重写** `/login` 端点：去掉 `OAuth2PasswordRequestForm`，改为直接接收 `UserLogin` JSON body
3. 同时删掉文件顶部不再需要的 `OAuth2PasswordRequestForm` import（`from fastapi.security import OAuth2PasswordRequestForm`）

```python
@router.post("/login", response_model=ResponseModel[TokenPayload])
def login(data: UserLogin, db: Session = Depends(get_db)):
    """登录：JSON body {email, password}，返回 JWT TokenPayload。"""
    try:
        user = UserService.authenticate(db, data)
        if not user:
            raise HTTPException(
                status_code=status.HTTP_401_UNAUTHORIZED,
                detail="邮箱或密码错误",
                headers={"WWW-Authenticate": "Bearer"},
            )
        token = UserService.issue_token(user)
        return ResponseModel(data=token)
    except HTTPException:
        raise
    except Exception as e:
        logger.exception("login 失败 email=%s: %s", data.email, e)
        raise HTTPException(
            status_code=status.HTTP_500_INTERNAL_SERVER_ERROR,
            detail="登录失败，请稍后重试",
        ) from e
```
