## 4. 常见问题排查

| 问题 | 可能原因 | 解决 |
|------|---------|------|
| SSE 不推送 | 后端 Redis 没启动 | 启动 Redis，确认 db=3 |
| SSE 401 | token 未传递 | 检查 `subscribeOnboardingEvents` 的 token 拼接 |
| 入驻提交 422 | 请求体字段不匹配 | 对比 `OnboardingRunRequest` schema 和前端组装的数据 |
| 词库列表为空 | A8 后端未执行 | 先确认后端 `/user/keywords` 返回数据 |
| 路由守卫死循环 | `onboarding_done` 标记缺失 | 确认 A5 入驻完成后写入了 `enterprise.settings.onboarding_done = True` |
