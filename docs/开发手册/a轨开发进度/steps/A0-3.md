## 3. 具体步骤

### 3.1 逐项检查 7 个常量

文件：`backend/app/agents/industry/packs/beauty_local/templates.py`

| 常量名 | 类型 | 最低要求 | 说明 |
|--------|------|----------|------|
| `BEAUTY_LOCAL_FORBIDDEN_WORDS` | `List[str]` | ≥10 条 | B4 机审禁词拦截用 |
| `BEAUTY_LOCAL_CHANNEL_WEIGHTS` | `List[Dict]` | =5 条 | 5 个渠道：托管页/小红书/知乎/大众点评/抖音 |
| `BEAUTY_LOCAL_DEFAULT_PERSONA` | `Dict` | 含 age_range/genders/core_needs/decision_factors/typical_queries | B1 persona 提示词用 |
| `BEAUTY_LOCAL_COMPETITORS_TEMPLATE` | `List[Dict]` | ≥3 条 | 3 类竞品：连锁/社区单店/工作室 |
| `BEAUTY_LOCAL_FACT_TEMPLATES` | `List[Dict]` | ≥3 组 | 每组含 title/category/tags/facts |
| `BEAUTY_LOCAL_SCENARIO_TEMPLATES` | `List[Dict]` | ≥3 条 | 每条含 user_query/intent/channel/skill |
| `BEAUTY_LOCAL_COMPLIANCE_CHECKLIST` | `List[Dict]` | ≥3 条 | 每条含 id/severity/description/enforcement |

### 3.2 重点检查：禁词列表

禁词列表是 **B4 机审的安全底线**，必须包含以下类别：

| 类别 | 示例词 | 原因 |
|------|--------|------|
| 极限用语 | 最、第一、顶级、国家级 | 《广告法》第九条 |
| 绝对化承诺 | 根治、永不复发、彻底治愈、100%有效 | 医疗广告管理办法 |
| 虚假安全 | 纯天然、无任何副作用、零风险 | 化妆品广告规范 |
| AI 相关 | AI自动生成、AI诊断、AI处方 | 平台合规要求 |

**当前 templates.py 已有 9 条**（`最, 第一, 顶级, 国家级, 全球第一, 全国第一, 行业第一, 纯天然, 无任何副作用, 零风险, 无副作用, 根治, 永不复发, 彻底治愈, 100%有效, 100%治愈, 祛斑100%, 祛痘永不复发, 美白根治` — 共 18 条，≥10 ✅），只需确认。

### 3.3 检查 compliance_checklist 结构

确认每条 CheckItem 包含以下 4 个字段：

```python
{
    "id": str,            # 唯一标识，如 "medical_words"
    "severity": str,      # "high" | "medium" | "low"
    "description": str,   # 人类可读说明
    "enforcement": str,   # 执行方式（机审/人工/混合）
}
```

当前已有 5 条 ✅，只需确认结构完整。

### 3.4 检查 `get_beauty_industry_templates()` 函数

确认此函数存在且返回的 dict 包含上述 7 个常量的 key。注意：此函数是 `seed.py` 的输入源，key 名缺失会导致 seed 报错。

---

## 4. 不可破坏的约束

- ❌ **禁止改变 7 个常量的类型** — 如 `BEAUTY_LOCAL_FORBIDDEN_WORDS` 必须是 `List[str]`，不能改 dict
- ❌ **禁止删除已有的禁词条目** — 只能追加，不可删除
- ❌ **禁止改变 compliance_checklist 的字段名** — `id/severity/description/enforcement` 是 schema 约定
- ❌ **禁止改变 `get_beauty_industry_templates()` 的返回 key 名** — seed.py 依赖
- ⚠️ **如果数据已经足够，就不要改任何东西** — 「不缺不补」原则
