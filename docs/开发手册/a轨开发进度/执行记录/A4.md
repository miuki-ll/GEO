### 审查结论：**A4-3 驳回 ❌**（A4-1 / A4-2 通过 ✅）

**驳回原因**：`embedding.py` 第 5 行 `from langchain_huggingface import HuggingFaceEmbeddings` 是顶层 import，导致测试 import `faiss_service` 时就触发 ImportError — mock 还没来得及挂上就炸了。测试本应不依赖真实 embedding 模型即可运行。

**修复方案**（二选一）：

1. **推荐**：`embedding.py` 改为延迟 import + 异常友好：
   ```python
   # embedding.py
   try:
       from langchain_huggingface import HuggingFaceEmbeddings
   except ImportError:
       HuggingFaceEmbeddings = None

   def get_embedding_function():
       if HuggingFaceEmbeddings is None:
           raise ImportError("langchain-huggingface 未安装，无法加载本地 Embedding 模型")
       # ... 其余不变
   ```
   这样 `faiss_service.py` import 不炸，只有真正调用 `get_embedding_function()` 时才报错。测试 mock 了 `_embedding_model`，永远不会走到真实加载。

2. 备选：安装 `langchain-huggingface` + `sentence-transformers`（约 2GB），但测试依赖应尽量轻。

**A4-1 / A4-2**：代码逻辑通过，无需改。修复 A4-3 后重新验收。
