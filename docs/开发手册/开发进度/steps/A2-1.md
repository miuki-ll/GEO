### 3.2 服务层（`kb_service.py` — FactService + _BaseKBService）

核对 `_BaseKBService` 基类方法的**租户注入**：

```
[ ] _list()    — q = db.query(cls.MODEL).filter(enterprise_id == enterprise_id)  ← 行 46
    所有筛选均在 enterprise_id 范围内；不会跨租户泄露数据

[ ] _get()     — filter(id==item_id AND enterprise_id==enterprise_id)             ← 行 82-86
    两个条件用 AND 连接

[ ] _create()  — payload["enterprise_id"] = enterprise_id                         ← 行 97
    强制写入 enterprise_id，不管 data 里有没有

[ ] _update()  — 先 _get(enterprise_id, item_id) → 不存在抛 ValueError          ← 行 125-127
    租户 B 改租户 A 的记录会触发 "记录不存在"

[ ] _delete()  — 同 _update，先 _get → 不存在抛 ValueError                       ← 行 146-149
```

### 3.3 Schema 层（`schemas/kb.py`）

```
[ ] KBFactCreate 字段：title(必填1-500) / content(必填≥1) / source_type(默认"manual")
    / source_ref(可选) / category(可选) / tags(List[str]默认为[]) / verified(默认False)

[ ] KBFactUpdate 字段：全部 Optional → Pydantic exclude_unset 实现部分更新

[ ] KBFactResponse 继承 KBFactBase + IDModel + TimestampResponse + enterprise_id + verified + embedding_id

[ ] KBFactListParams 继承 PaginationParams，额外字段 category/verified/source_type
    PaginationParams 定义在 schemas/common.py：page(默认1) / page_size(默认20) / keyword(可选)
```
