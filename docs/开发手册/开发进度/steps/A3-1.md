## 3. 改动清单

### 3.1 改动 1：schemas.py — 新增 SearchCitation

**文件**：`backend/app/core/llm/schemas.py`

**位置**：`EmbeddingResponse` 类定义之后（文件末尾）

**改什么**：新增 `SearchCitation` 类，表示联网搜索返回的单条引用

```python
class SearchCitation(BaseSchema):
    """联网搜索返回的单条引用 — 豆包 Responses API 的 url_citation annotation"""
    url: str = ""
    title: str = ""
    summary: str = ""  # 豆包返回 1200+ 字摘要，足够分析痛点/场景/竞品
    site_name: str = ""
    publish_time: Optional[str] = None
```

### 3.2 改动 2：schemas.py — 新增 SearchRequest

**位置**：`SearchCitation` 之后

**改什么**：代表一次联网搜索请求

```python
class SearchRequest(BaseSchema):
    """联网搜索请求 — 指定引擎、查询词、超时等"""
    engine: Optional[str] = None     # 默认 doubao
    model: Optional[str] = None
    query: str = Field(..., min_length=1, max_length=500)  # 搜索查询
    max_keywords: int = Field(3, ge=1, le=10)              # web_search 关键词数
    limit: int = Field(10, ge=1, le=20)                    # 返回引用数上限
    timeout: Optional[int] = None                           # 联网搜索建议 ≥180s
    trace_id: Optional[str] = None
    extra: Dict[str, Any] = Field(default_factory=dict)
```

### 3.3 改动 3：schemas.py — 新增 SearchResponse

**位置**：`SearchRequest` 之后

**改什么**：代表一次联网搜索的完整响应

```python
class SearchResponse(BaseSchema):
    """联网搜索响应 — AI 总结 + 引用列表 + 用量"""
    engine: str
    model: str
    answer: str = ""                                  # AI 对搜索结果的总结回答
    citations: List[SearchCitation] = Field(default_factory=list)
    usage: LLMUsage = Field(default_factory=LLMUsage)
    error: Optional[str] = None
    latency_ms: int = 0
    trace_id: Optional[str] = None
    extra: Dict[str, Any] = Field(default_factory=dict)

    @property
    def ok(self) -> bool:
        """判断搜索是否成功：无错误且有回答内容"""
        return self.error is None and bool(self.answer)
```

### 3.4 改动 4：base.py — 新增 search() 可选方法

**文件**：`backend/app/core/llm/base.py`

**位置**：`embed()` 抽象方法之后，`resolve_model()` 之前

**改什么**：新增非抽象的 `search()` 方法，默认返回"不支持"。DoubaoAdapter 会覆盖此方法实现真实搜索，其他引擎保持默认（后续 gateway.search() 会自动降级到 chat 模拟）。

```python
async def search(self, request: "SearchRequest") -> "SearchResponse":
    """联网搜索 — 可选实现。仅豆包支持真联网搜索，其他引擎默认返回不支持"""
    from app.core.llm.schemas import SearchRequest, SearchResponse, SearchCitation
    return SearchResponse(
        engine=self.ENGINE_CODE,
        model="",
        error=f"[{self.ENGINE_CODE}] 不支持联网搜索",
    )
```

> ⚠️ **注意**：文件头部 import 不在此步修改 — import 在 base.py 已经是顶层 import schemas 模块的方式，`_load_config()` 和 `chat()` 已经 import LLMRequest/LLMResponse。本次不变更 import 区，`search()` 内部延迟 import 避免循环引用。
