## 3. 具体步骤

### 3.1 检查 pack.py 类属性

文件：`backend/app/agents/industry/packs/beauty_local/pack.py`

确认：

```python
class BeautyLocalPack(IndustryPack):
    code = "beauty_local"
    name = "生美本地 · 皮肤管理"
```

- `code` 必须是 `"beauty_local"` — 这是 registry 的 key，也是 `get_industry_pack("beauty_local")` 的入参，B 轨代码中硬编码了这个字符串
- `name` 用于前端展示，不可为空

### 3.2 检查 6 个方法的委托关系

确认每个方法只做委托，不包含业务逻辑：

| 方法 | 委托目标 (templates.py) | 返回方式 |
|------|------------------------|----------|
| `forbidden_words()` | `tpl.BEAUTY_LOCAL_FORBIDDEN_WORDS` | `list(...)` |
| `channel_weights()` | `tpl.BEAUTY_LOCAL_CHANNEL_WEIGHTS` | `list(...)` |
| `default_persona()` | `tpl.BEAUTY_LOCAL_DEFAULT_PERSONA` | `dict(...)` |
| `fact_templates()` | `tpl.BEAUTY_LOCAL_FACT_TEMPLATES` | `list(...)` |
| `scenario_templates()` | `tpl.BEAUTY_LOCAL_SCENARIO_TEMPLATES` | `list(...)` |
| `compliance_checklist()` | `tpl.BEAUTY_LOCAL_COMPLIANCE_CHECKLIST` | `list(...)` |

关键检查：
- 每个方法中是否正确使用了 `list()` 包装（防止外部修改原始常量）
- `default_persona()` 是否用了 `dict()` 而不是 `list()`
- import 路径：`from app.agents.industry.packs.beauty_local import templates as tpl`

### 3.3 检查 registry 注册

文件：`backend/app/agents/industry/registry.py`

确认：
```python
from app.agents.industry.packs.beauty_local.pack import BeautyLocalPack

_REGISTRY: Dict[str, IndustryPack] = {
    BeautyLocalPack.code: BeautyLocalPack(),
}
```

- `BeautyLocalPack` 已导入
- `_REGISTRY` 中以 `BeautyLocalPack.code`（即 `"beauty_local"`）为 key 注册了实例
- `get_industry_pack("beauty_local")` 可正常返回非 None 实例
