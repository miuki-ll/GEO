## 1. MVP-A 最小路径（优先验收）

```
生美 1 店 · 8 步跑通：
  入驻(选主攻AI+填店) → 诊断(探针LLM生成·5项) → 词库(四源汇聚)
  → 方案包(persona+scenario LLM生成·勾选2个) → 内容工厂(scenario模式·RAG切片)
  → 内容检测(5项·含RAG验证) → 人闸门(策略+草稿合并)
  → 发布(托管页AUTO+小红书SEMI) → 监控(24h T0/T1对比)
  → 效果舱(四层漏斗+转化闭环)
```
